---
title: Your first project
description: Open a Hydrogen project and make your first build.
---
Quark starts with a **Start Window**. Choose **Open a project or solution** to open an existing Hydrogen `.hyproj` file, or **Create a new project** to use the native project wizard.

1. Open the Start Window and choose an existing project, local folder, or new project.
2. In the IDE, look for **Solution Explorer**. Open a `.hy` source file.
3. Set up the Hydrogen compiler (see [Build and run](/Quark-Docs/docs/build/)).
4. Select the project to build and choose **Build Solution**.
5. Read the result in the **Output** pane.

![Older Quark welcome screenshot](/Quark-Docs/images/quark-welcome.png)

*Screenshot from an earlier Quark Development interface. The current native Start Window may differ.*

:::note
Opening a `.hyproj` as a text file is not the same as **opening it as a project**. Use the project-opening command to register it in your workspace.
:::
