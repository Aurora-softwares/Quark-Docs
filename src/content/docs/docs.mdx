## A note about development builds

Quark is moving toward a native desktop frontend. Features that are still being verified on Linux, Windows or macOS are labelled as development work, not promised as release-ready. Screenshots on this site are genuine Quark development captures, and some show the previous interface.

See [what works today and what still needs testing](/Quark-Docs/docs/status/), or [suggest an improvement on GitHub](https://github.com/Aurora-softwares/Quark-IDE/issues).
